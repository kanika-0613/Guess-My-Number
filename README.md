# Guess My Number 🎯

A simple number guessing game built using HTML, CSS and JavaScript.

## Features

- Random secret number generation
- Guess validation
- Score tracking
- High score tracking
- "Again" button to restart the game
- Visual feedback for correct and incorrect guesses

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

Guess a number between 1 and 20.

- "Too High!" → your guess is higher than the secret number
- "Too Low!" → your guess is lower than the secret number
- "YAY!! Correct Number!" → you guessed it!

The goal is to get the highest score possible.
